キャンバスをズームインするには、Ctrl + 「+」キー（Windows）または Cmd + 「+」キー（Mac）を押します。ズームアウトするには、Ctrl + 「-」キー（Windows）または Cmd + 「-」キー（Mac）を押します。

キャンバスをパン（移動）するには、マウスまたはタッチパッドを使用してスクロールします。

キャンバスの位置とサイズをデフォルト値に戻すには、Ctrl + 「0」キー（Windows）または Cmd + 「0」キー（Mac）を押します。
